# 复测题目重复Bug修复

## 问题描述

测评模式连续测了3次（包括提高难度测试），4个题目完全一模一样。

## 根因分析

### Bug (P0)：`goToRetest()` 传递旧 `assessmentId`

**文件**: `pages/result/result.js:276-277`

```js
goToRetest() {
  // ...
  const params = [`retest=true`];
  if (this.data.assessmentId) {
    params.push(`assessmentId=${this.data.assessmentId}`);  // ← BUG：传递旧ID
  }
  // ...
  wx.navigateTo({ url: '/pages/assessment/assessment?' + params.join('&') });
}
```

**文件**: `pages/assessment/assessment.js:41-44`

```js
// 优先从 URL params 获取 assessmentId
if (options.assessmentId) {
  this.setData({ assessmentId: options.assessmentId });
  this.loadAssessment(options.assessmentId);  // ← 加载旧题目
  return;  // ← 跳过 initAssessment()
}
```

**根因链**：
1. 首次测评 → `initAssessment()` → 创建队列 → 生成新题目 → 显示结果
2. 点击"重新测评" → `goToRetest()` → 传 `assessmentId=<旧ID>`
3. assessment 页面 `onLoad` 检测到 `assessmentId` → `loadAssessment(旧ID)` → 加载旧题目
4. 用户看到相同题目

## 修复方案

### 1. `pages/result/result.js` — 不传 assessmentId

```js
goToRetest() {
  // ...
  const params = [`retest=true`];
  // 不传 assessmentId，让 assessment 页面创建新任务
  if (this.data.score > 0) {
    params.push(`previousScore=${this.data.score}`);
  }
  params.push(`targetDifficulty=${targetDifficulty}`);
  wx.navigateTo({ url: '/pages/assessment/assessment?' + params.join('&') });
}
```

### 2. `pages/assessment/assessment.js` — 复测优先走 initAssessment

```js
onLoad(options) {
  // ...
  // 复测模式：不使用旧 assessmentId，创建新任务
  if (options.retest === 'true') {
    this.setData({ isRetest: true });
    // 不检查 assessmentId，直接走 initAssessment
    wx.removeStorageSync('currentAssessmentId');
    this.initAssessment();
    return;
  }
  // ...
}
```

## 修改文件

| 文件 | 修改 |
|------|------|
| `pages/result/result.js` | `goToRetest()` 移除 `assessmentId` 参数 |
| `pages/assessment/assessment.js` | `onLoad` 复测模式跳过 assessmentId 检查 |
