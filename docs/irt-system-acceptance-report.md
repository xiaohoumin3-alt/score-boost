## 使用方式

### 用户完成测评后

```
小程序前端 → submitAnswer（判分）
    ↓
自动触发 scoreCalibration（预估分数）
    ↓
返回 score_estimation（预估分 + 置信度 + 等级）
```

### 预估结果示例

```json
{
  "estimatedScore": 70,        // 平时分
  "examScore": 106,            // 中考预估分
  "level": "C",               // 等级
  "levelText": "及格",         // 等级说明
  "confidence": 87,            // 置信度 %
  "margin": 1,                 // 误差范围
  "theta": 0,                  // IRT 能力值
  "se": 0.447                  // 标准误
}
```
