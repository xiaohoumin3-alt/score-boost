## 🔧 技术细节

1. 页面onLoad时自动执行
2. 循环生成315条测评记录
3. 批量写入assessments集合
4. 更新ai_question_pool的usage_count
5. 实时显示进度和结果

**特点**：
- 无需用户手动操作

- 直接在小程序环境中执行

## 🚨 注意事项

1. **页面会自动执行**：打开后立即开始数据导入
2. **不能重复执行**：每次打开都会重新导入，避免重复执行
3. **网络要求**：需要稳定的网络连接
4. **云函数配额**：批量写入会消耗云数据库写入次数
