# 家长测评真实验证步骤

## 验证环境
- 微信开发者工具
- 项目：score-boost-mini

## 验证步骤

### 1. 打开项目
```bash
# 在微信开发者工具中打开项目目录
/Users/seanxx/score-boost-mini
```

### 2. 导航到家长测评页面
- 点击"我的"标签页
- 点击"家长测评"菜单项
- 确认进入家长测评页面

### 3. 验证年级选择器
**操作**：
1. 点击"选择孩子年级"选择器
2. 选择"二年级"

**预期**：
- 选择器显示"二年级"
- 开始按钮仍然禁用（因为科目未选择）

### 4. 验证科目选择器（新功能）
**操作**：
1. 点击"选择科目"选择器
2. 选择"语文"

**预期**：
- 选择器显示"语文"
- 开始按钮变为可点击状态

### 5. 验证开始测评
**操作**：
1. 确认年级为"二年级"，科目为"语文"
2. 点击"开始测评"按钮

**预期**：
- 显示加载动画"加载中..."
- 约1-3秒后进入答题页面
- 页面标题显示"家长答题"
- 显示5道语文题目

### 6. 验证答题流程
**操作**：
1. 选择第1题答案
2. 点击"下一题"
3. 重复直至第5题
4. 点击"提交"

**预期**：
- 每题答案可选
- 选择答案后"下一题"按钮可点击
- 提交后显示家长得分

### 7. 验证其他科目
重复步骤3-6，测试：
- 年级：五年级，科目：数学
- 年级：初二，科目：英语

## 验证检查清单

- [ ] 年级选择器可以选择并正确显示
- [ ] 科目选择器可以选择并正确显示（数语英）
- [ ] 开始按钮在两者都选中时才启用
- [ ] 点击开始后显示加载动画
- [ ] 加载完成后进入答题页面
- [ ] 答题页面显示正确科目题目
- [ ] 可以正常选择答案并提交
- [ ] 提交后显示得分结果

## 预期结果

### 正常场景
- 二年级语文 → 5道语文题目（拼音、识字等）
- 五年级数学 → 5道数学题目（小数、简易方程等）
- 初二英语 → 5道英语题目（定语从句、被动语态等）

### 异常场景
- 题库不足时AI自动生成题目
- 生成超时显示错误提示
- 云函数失败显示错误提示
