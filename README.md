# 提分神器 - AI个性化学习系统

> AI实时生成针对性题目，从"不会"练到"会"

## 产品定位

一款覆盖K12全科（1-9年级）的AI个性化学习系统，核心能力是**实时生成针对性题目**，而非从预置题库抽题。

---

## 核心能力

### AI原生出题
- **实时生成**：根据学生薄弱点，AI实时生成新题目
- **非题库抽题**：每道题都是AI现场生成的，针对性极强
- **自适应难度**：连续3题正确→降难度，连续2题错误→升难度
- **智能提示**：分级提示，不直接给答案，培养思考能力

### 学习记忆系统（Memory）
- 记录每个知识点的掌握程度
- 自动生成复习计划
- 追踪学习趋势
- 连续学习天数激励

### 每日任务
- AI根据学生水平生成每日练习
- 自动识别薄弱知识点
- 推荐当天应攻克的内容

## 技术架构

### 云函数（75个）
核心云函数包括：
- `generateAiQuestion` - AI单题生成
- `questionGenerator` - 后台队列批量生成
- `studentMemory` - 学习记忆系统
- `startAssessment` - 启动评估
- `submitAnswer` / `practice_v2` - 练习结果处理
- `generateDailyTask` - 每日任务生成
- `batchEvaluate` - 批量评估分析

### 数据库
- `assessments` - 评估记录
- `ai_question_pool` - AI题目池
- `student_memory` - 学生记忆
- `knowledge_points` - 知识点数据（近3万条）
- `practice_records` - 练习记录
- `daily_tasks` - 每日任务

### LLM集成
- **模型**：DeepSeek (deepseek-chat)
- **超时**：45秒
- **重试**：2次
- **个性化Prompt**：根据学生历史表现动态调整

## 核心差异

| 传统题库产品 | 提分神器 |
|--------------|----------|
| 从题库抽题 | AI实时生成 |
| 题目有限，可能重复 | 永远不重复，针对性极强 |
| 无法理解学生薄弱点 | AI分析薄弱点，精准出题 |
| 固定难度 | 自适应难度 |
